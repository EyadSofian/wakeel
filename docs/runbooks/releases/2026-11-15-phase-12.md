## Remaining acceptance gaps

This is a deployment record, not completion of task 15.5. Railway sandbox runtime isolation is still unverified: `SANDBOX_RUNTIME_VERIFIED` is not asserted and the existing sandbox development setting remains. The deny-all outbound network policy and the parser isolation requirements are not demonstrated on this host. The manual database dump is not scheduled PITR or a completed restore drill. Real model evaluations need usable provider credentials and credits. Phase 12.2 screen states and normal/reduced motion were subsequently reviewed; see `docs/design-reviews/12.2-evals.md`.

Do not present this environment as having passed production security acceptance or the remaining Phase 13–15 gates.
