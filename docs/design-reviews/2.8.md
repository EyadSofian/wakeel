Fixes made:
- `Kbd` sets `font-sans`, so keys use the type system's face; ⇧ and ⌘ now match the letters (`packages/ui/src/components/Tile.tsx`).
- Workflow names in the Workflows panel are isolated with `<bdi>`, as on the Variables screen (2.7). That turned up the same problem in the Issues panel: a message that quotes an Arabic name, such as `"مساعد الطلبات" has no instructions.`, had `dir="auto"` and flipped the whole English sentence. Messages and fixes now render LTR; only the names in the location path are isolated, one `<bdi>` per name (`issueLocationParts`).
- New shot states: `issues-panel-rtl` (the issues fixture with the RTL names), `issues-panel-empty` (a clean bot, opened from the palette because the top bar shows no count) and `save-offline` (PUT aborted as "internet disconnected", one nudge, the top bar shows "Offline — changes kept locally").
- The palette and the node and card menus show search focus as one accent underline (`focus-within:border-accent` on the label) and the input drops the clipped ring (`.wk-focus-underline` in `tokens.css`, next to the global ring rule).

## Behaviour found while testing (fixed, not visual)

- Running "Show issues" from the palette opened the Issues panel while the palette was still fading out. With two Radix dialogs layered, `Esc` sometimes went to the leaving one and the panel would not close by keyboard (the e2e failed about one run in three). The palette now runs the chosen row once its focus scope has unmounted, so only one dialog is ever open.
- Searching "الطلبات" does not find a workflow named "طلبات الاسترجاع": the palette's fuzzy match folds hamza, diacritics and letter forms but does not strip the definite article. That is light stemming and belongs with the search normaliser in `packages/retrieval` (phase 9), which the palette should then reuse.
