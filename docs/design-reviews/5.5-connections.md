# Design review — 5.5 Connections

Screens: connections (default, focus, empty, loading, error, rtl), connection / Setup (default, focus, empty, loading, error, rtl), connection-disabled (default, rtl), connection-deliveries (default, empty, loading, error, rtl), connection-test (default, tested, rtl) · light + dark · 1440, 1280

Motion: no new moments. The create, key, revoke and shown-once dialogs are the existing `Dialog` (its entrance was reviewed in task 1.7); tabs are links, as in Settings.

## Pass 1

| # | Check | Result | Evidence |
|---|---|---|---|
| 1 | Accent use | pass | connections-default: accent only on "New connection" (the one primary action), the active rail item and the active tab; Setup's "Save changes" is the only primary button there |
| 2 | Gradients, glows, decoration | pass | Code blocks are `subtle` caption bars over a hairline border; no fills or glows |
| 3 | Status colours | pass | Green, amber and red appear only in the status and delivery badges and in the error and success banners |
| 4 | Dark hierarchy | pass | connections-rtl-dark, deliveries-dark: rows on surface, header on `subtle`, badges keep their tone on the dark `*-subtle` backgrounds |
| 5 | Weights, sizes, caps | pass | Titles `text-title`, rows `text-body`, help `text-small`, codes mono `text-code-small`; no capitals beyond sentence case |
| 6 | Sentence case | pass | "New connection", "Signing secret", "Finish rotation", "Send test event", "Message as a user", "Send again" |
| 7 | Truncation and overlap | pass | Long webhook URLs show only the host in the list; the long-token connection name truncates with an ellipsis in rtl |
| 8 | Radii | pass | Tables 14, code blocks and banners 10, inputs and buttons 8 |
| 9 | Shadows | pass | None added |
| 10 | Spacing | pass | Sections 40 apart, section title to content 20, form fields 24, as on the Settings screens |
| 11 | Identical card grids | pass | Connections, keys and deliveries are tables |
| 12 | One icon set | pass | Lucide; the rail's Connections item is `Cable` at the rail's 20 px and stroke |
| 13 | Selection and primary action | pass | The active tab carries the accent underline; each section has at most one action group on the right |
| 14 | Empty space | pass | Forms are held to the inspector's maximum width, as on General settings; tables span the page |
| 15 | RTL fixtures | fail | connections-rtl: Arabic names were right-aligned inside their cells (`dir="auto"` on a block), leaving a gap of a whole column before them; same for key names on Setup |
| 16 | Names and errors | fail | deliveries-default: the `fetch_failed` row read "The request to {host} failed: {message}" — the errors.ts title for bot code, with placeholders a delivery has no values for |
| 17 | States | fail | connection-error: the title stayed a skeleton next to the error banner, as if still loading |
| 18 | Focus ring | pass | connections-focus: the ring is on the brand link, the first focusable control |
| 19 | Beside Linear or Figma | fail | The raw `{host}` placeholder (16) is the one thing that would look broken |

Fixes made:

- 15: names render in `<bdi>` inside the link or cell, as the Variables screen does: each keeps its own direction but starts at the column's start.
- 16: the Connections model words `fetch_blocked`, `fetch_failed` and `rate_limited` for a webhook ("The webhook endpoint could not be reached", with a fix). A unit test checks that no code a delivery can carry shows a `{placeholder}`.
- 17: when the connection cannot be loaded, the header says "Connection" and the banner says what happened.
