## Motion and interaction evidence

`pnpm studio:motion --screen settings-models`: four required tests passed (normal/reduced entrance frames and unpaused keyboard flows). The command excludes 24 unrelated canvas/emulator tests through the existing screen selector. Both selected keyboard flows passed without retries. Recorded videos live under `apps/studio/test-results/motion-models-*/video.webm`. Frames at 0/25/50/75/100 and timing JSON live under `.motion/settings-models/`; the actual frames were opened. Normal opacity uses 240 ms and a gentle transform spring; reduced motion uses only the 80 ms opacity fade. No new component animation numbers were introduced.

`pnpm studio:shots --screen settings-models --update`: 34 passed, consisting of 32 screen/state/theme/width combinations plus two shared Arabic/long-token content checks. The original snapshot comparison failed as expected after adding provider rows and a third model field; the new baselines remain review candidates.
