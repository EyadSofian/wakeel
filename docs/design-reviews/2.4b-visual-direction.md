Fixes made:
- Output labels use the physical `ml-auto` (outputs are always on the end edge); node names use `text-left` with `dir="auto"`, so Arabic names keep their order but sit next to the icon.
- Chips use 8 px side padding; all five fit on one row at 272 px.
- Minimap blocks take their node's category border colour (`nodeClassName` + `.wk-mm-<category>`).
- Gallery: radius scale 4/8/10/14/18, buttons 28/32/40, `--accent-text` for links, new Node categories section.
