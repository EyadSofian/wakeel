Fixes made:
- Composer field and send button `rounded-sm` (8); node menu `rounded-md` (10) (8).
- `TranscriptList` keeps a reader who was at the bottom there when the list resizes (ResizeObserver), so opening Variables or the user form never hides the newest message (7).
- The Variables tab is capped at half the panel (`max-h-1/2`), so the transcript keeps at least half (14).
- Bare URLs are isolated as left-to-right runs (`dir="ltr"`) in markdown and in plain text, and wrap with `break-words`, so a URL moves to its own line first and only breaks when it is longer than the bubble (15).
- The shots wait for finite animations to finish before shooting; the typing loop is excluded (17, 19).
- The transcript stays mounted and shows the empty state inside itself, so the first message enters like every other (motion).
- Choice buttons, the typing indicator and transcript fades use `duration.instant` (80 ms) when motion is reduced (motion).
- Not from this screen: the shots now run at a fixed clock (2026-11-13 18:40 UTC), because the home screen's relative dates ("10 hours ago") changed with the day and failed the baseline. The `canvas card-ask` baselines were also out of date from earlier Inspector copy changes ("Question", the type badge) and were refreshed.
