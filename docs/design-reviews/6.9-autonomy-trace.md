Screens: emulator — `trace-payload` (new: an Autonomous Node's turn with its first model call open), `trace-playback` (new: a replay of a three-step turn paused on its second card), `trace` (its header gained the playback controls), and every other emulator state · light + dark · 1440, 1280

Motion: `pnpm studio:motion --screen emulator`: trace playback (new) at normal and reduced motion, plus the 4.6/4.7 interactions, which still pass.

Fixes made:
- A newly selected step's details scroll into the trace area's view (`scrollIntoView`, `block: "nearest"`, smooth only without reduced motion) (7).
- Prose payloads (prompt messages, replies, string outputs) render in the body face; code and JSON stay mono. Arabic in the payload now shapes correctly (15).
- While a replay runs, the canvas centres the node it is on, opening its workflow if needed, with the same 240 ms jump as clicking a step (none with reduced motion) (19, follow).

Known and left as is:
- The trace area is short beside a long autonomous trace; scrolling to the details hides the selected row. Making the area resizable is a separate change to §5.3's layout.
- Payloads over 8 KB (most prompts, in production) show a 400-character preview: the object store path for trace payloads (ADR-009) is not built yet. The fixtures use inline payloads.

Baselines updated: `emulator-trace-{light,dark}-1280` (header controls) and the eight new `trace-payload` and `trace-playback` images.
