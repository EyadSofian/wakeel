Fixes made:
- `Table` takes `fixed`; every variable, input and output table uses the same column fractions (4/2/2/2/1/1 and 4/2/2/3/1), so columns line up down the page. Long names truncate.
- "Add input" and "Add output" are the same secondary compact button as "Add variable".
- Group titles isolate their text with `<bdi>` instead of `dir="auto"`, so an Arabic workflow name keeps its direction and stays at the start.
- "Used in" counts uses ("4 uses"); the dialogs say "4 uses in 3 places" and list one row per place with "· 2 times" where it repeats. The Condition field reads "Rule".
- The breadcrumb shows a skeleton for the workspace name until it loads.
- The picker's search field has rounded top corners.

## Behaviour found while testing (fixed, not visual)

- Opening a usage from the Variables screen crashed the canvas with "Maximum update depth exceeded". xyflow reports an empty selection once while it mounts; the store took it, and then the store and xyflow kept correcting each other. The canvas now ignores selection reports until xyflow has initialised, and centres on the selected node when it opens with one.
