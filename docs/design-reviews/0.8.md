Fixes made:
- Space bars use `bg-strong` (neutral); labels are `whitespace-nowrap` in a 64 px column and drop the "px" (the note says values are px).
- Content bubbles use `wrap-anywhere`; a Playwright check asserts the long token does not overflow.
- `LeftRail` takes an `active` destination; the gallery passes none.
- Colour grid aligns to the top; status token sits after a flexible label.
- "Publish" has no icon; "Add card" carries the plus.
- RTL line height: Vite's default CSS target rewrote `:dir(rtl)` as `:lang(ar…)`, which never matches `dir="auto"` content. `build.cssTarget` is now Chrome 120 / Edge 120 / Firefox 128 / Safari 16.4 (Tailwind 4's floor, raised for `:dir()`); a Playwright check asserts 1.75 on Arabic and 22 px on English.
- Router states: `NotFoundState` and `ErrorState` built from `errors.ts`, added as screens `not-found` and `error`.

## Motion

Interaction: gallery "Show details" popover enter.

Pass 1 found two problems:
- The frame tool used a paused page clock, but Motion runs opacity and transform as Web Animations, which that clock does not drive: every frame showed the panel at opacity 0. The spec now pauses and seeks the page's Web Animations and records their measured timing.
- Measured timing showed opacity on the spring (350 ms). §2.6 reserves springs for travel; opacity and colour use `ease.out`. `enterTransition()` and `exitTransition()` in `packages/ui/src/motion.ts` now give travel `spring.gentle` and opacity a 240 ms `ease.out` tween, with unit tests.

Pass 2, measured:

| Mode | Property | Duration | Expected (§2.6) | Result |
|---|---|---|---|---|
| normal | opacity | 240 ms, ease-out | `duration.slower`, `ease.out` | pass |
| normal | transform (8 px down) | 299 ms to settle | `spring.gentle`, visualDuration 240 ms | pass |
| normal | button background | 80 ms | `duration.instant` | pass |
| reduced | opacity | 80 ms | 80 ms opacity only | pass |
| reduced | transform | none | no travel | pass |

Frames (normal): 0% hidden; 25% faint, about 3 px above rest; 50% nearly opaque, about 1 px above; 75% and 100% at rest with no visible overshoot. Frames (reduced): the panel is at its final position in every frame; only opacity changes.

Result: pass (all 19) on pass 3; motion pass on pass 2.
