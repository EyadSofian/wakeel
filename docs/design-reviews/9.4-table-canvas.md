# Design review — 9.4 Table cards and tools

Screens: Table card and Table tool Inspector with Arabic canvas content, light at 1440 and dark at 1280. The browser test also checks that both edits reach the draft save request.

Pass 1. The native operation multiselect showed only two choices and drew a dropdown chevron (checks 7, 14 and 19). The upsert label occupied more space than its field needed (check 6).

Fixes made. Use a labelled checkbox group with keyboard focus for all six tool operations. Shorten the upsert label to “Unique column” and describe how it matches the row.
