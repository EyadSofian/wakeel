The video shows the settle | pass (settle verified in video only) |
| Transition drawing | Line follows the pointer with no easing; valid target shows its start edge in `--accent-border` | connect-normal-midway: line follows the pointer in the accent; over-target: the target node has the accent start edge and border | pass |
| … on release | End snaps with `spring.snappy`; an invalid release retracts in 120 ms | xyflow removes the connection line on release and the transition appears in place: no snap, no retract | **not done** |

Not done, and why: the release snap and retract need a custom connection line that outlives xyflow's drag (xyflow 12 unmounts it on pointer up). That is motion polish; it is listed for task 13.2 (motion pass) rather than built here.
